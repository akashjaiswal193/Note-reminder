# Notes Management Application

A Notes Management Web Application built using HTML, CSS, and JavaScript.

## Features

* Create and save notes
* Store data in Local Storage
* Display notes dynamically using DOM Manipulation
* Form validation for all input fields
* Category-based note management:

  * Emergency
  * Important
  * Urgent
  * No Rush
* Filter notes by category
* Navigate through notes using Previous and Next buttons
* Display profile image, name, hometown, and purpose
* WhatsApp integration for quick messaging
* Responsive dark-themed user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
* DOM Manipulation

## Project Workflow

1. User creates a note through the form.
2. Data is validated before submission.
3. The note is stored in Local Storage.
4. Notes are displayed on the main page.
5. Users can navigate between notes using Previous and Next buttons.
6. Notes can be filtered based on their category.
7. WhatsApp integration allows direct communication with saved contacts.
